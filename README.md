# PortfolioDraco10101

Portfolio repository for the DRACO1010 / Draco10101 web portfolio.

## Current status

This repository currently contains its MIT license and this README. It does not yet contain a website entry point or portfolio source files, and GitHub Pages is not enabled.

The separate `Draco-Website` repository is the portfolio scaffold with GitHub Pages enabled. Confirm which repository should be the canonical portfolio before publishing duplicate copies of the same site.

## Safe publishing workflow

1. Back up the complete working portfolio.
2. Upload the actual site files and preserve their relative paths.
3. Preview the page on mobile and desktop.
4. Enable GitHub Pages only after the entry point and assets are present.
5. Use a pull request for review before merging.

Existing commits and the MIT license should be preserved.
